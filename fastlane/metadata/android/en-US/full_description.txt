TurboNotes edits a folder of plain Markdown files. Point it at any folder, for example one Syncthing keeps in sync with your computer, and every .md and .markdown file in it and its subfolders shows up in a file tree.

<ul>
<li><b>File tree</b> of the notes folder, folders first; hidden folders such as .git or .obsidian are skipped.</li>
<li><b>Fuzzy finder</b>: type a few letters of a note's path to jump to it.</li>
<li><b>Full-text search</b> across all notes that forgives typos, with #tag filters.</li>
<li><b>Pinned and recent notes</b>, and a <b>tag tree</b> built from #tags that filters the file tree.</li>
<li><b>Images</b> from the gallery, the camera or the clipboard are stored next to the note and shown inline.</li>
<li><b>Share</b> a note to other apps as text, PDF or image.</li>
<li><b>Quick capture</b>: a home-screen widget and a share target add text or images to the default note without opening the app.</li>
<li><b>Raw editor</b> for the Markdown source exactly as it is on disk.</li>
<li><b>WYSIWYG editor</b> that shows headings, bold, italics, lists, tasks, quotes, links and code formatted as you type, with a formatting toolbar. It edits the same Markdown text, so switching editors never reformats a note.</li>
<li><b>Default note</b> (TurboNote.md, configurable) one tap away behind the lightning bolt button, ready for typing.</li>
<li><b>Autosave</b> whenever you leave a note or the app. A note that changed on disk in the meantime is never overwritten silently.</li>
<li>Create, rename, move and delete notes.</li>
<li>Use the Android folder picker for a notes vault without broad storage permission, or type a path.</li>
</ul>

Optional S3 sync sends Markdown notes to your own S3-compatible bucket when you choose Sync now. Independent edits merge; unresolved edits become conflict notes. Sync is off by default. Images stay local and deletions are not propagated. No telemetry; your local notes remain plain files.
